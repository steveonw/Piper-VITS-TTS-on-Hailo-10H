# Redistribution / licensing note

This packet contains deployment scripts, metadata and test scaffolding for an experimental Hailo-10H port of a Piper/VITS voice backend.

The two HEF binaries are derived from the Amy Medium voice model. Before publishing or redistributing those model-derived binaries, the distributor should independently review the source model and dataset licensing terms.

Useful source references:

- Amy Medium:
  https://huggingface.co/rhasspy/piper-voices/tree/main/en/en_US/amy/medium
- Amy Medium model card:
  https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/amy/medium/MODEL_CARD
- Piper voice repository:
  https://huggingface.co/rhasspy/piper-voices

This file is a caution for release packaging, not legal advice.
